Browser Extensions

YouTube Transcript

Leave this blank to use YouTube's default caption selection. The setting applies to both transcripts and SRT subtitles.

X Bookmarks

The exporter collects bookmarks into a local IndexedDB archive and downloads a cumulative JSON file. Open it after signing in to X and reloading the bookmarks page.

Allow Right-Click

Open the toolbar popup on any page to enable or disable right-click, selection, copy, paste, and drag restoration for that tab.

Onefile

Open the toolbar popup on any page and choose Save page to download a self-extracting offline archive.
